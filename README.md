# B站内容读取

**把 B站视频发给 AI 机器人，和它聊视频信息、可用字幕和热门评论。**

分享一个视频链接，问一句「主要讲了什么」「评论区怎么看」，机器人就能根据实际读到的资料回答。也可以让它按关键词找视频。

<img src="logo.png" width="120" alt="B站内容读取插件图标">

## 能做什么

- **读视频资料**：读取标题、简介、UP主、可取得的粉丝数和播放、点赞等互动数据。
- **读可用字幕**：提取字幕节选，帮助机器人了解视频内容；没有可用字幕时使用视频简介。
- **看热门评论**：读取部分热门评论，了解观众在讨论什么。
- **搜索视频**：按关键词寻找视频，返回标题和链接。
- **继续追问**：分享后可以接着问，也可以引用之前的视频卡片再提问。

适用于 **AstrBot 4.29.3 及以上、Python 3.12**。已验证 AstrBot 4.29.3，消息接入为 QQ / OneBot。

## 安装

1. 在 **AstrBot → 插件市场** 搜索「B站内容读取」，点击安装。
2. 等待 AstrBot 安装 Python 依赖，确认插件已启用。
3. 为 AstrBot 配置可用的聊天模型。
4. 按下面的步骤登录 B站。

本插件直接连接 B站，所需 Python 依赖由 AstrBot 安装，正常使用时无需额外部署读取服务。

## 扫码登录

打开 **AstrBot → 插件 → B站内容读取 → 插件视图 → 账号与状态**。

1. 点击 **验证当前登录**。已登录时可以直接开始使用。
2. 如果尚未登录，点击 **获取登录二维码**。
3. 使用手机上的 **哔哩哔哩 App** 扫码，并在手机上确认。
4. 再次点击 **验证当前登录**，确认页面显示已登录。

二维码过期后重新获取即可。登录失效时，回到这个页面重新扫码。

## 怎么使用

### 私聊视频

复制 B站视频分享链接，发给机器人，然后提问：

> 帮我总结这个视频。你读到的是字幕还是简介？评论区在讨论什么？

支持视频网页链接、`b23.tv` 短链接和 BV 号。

### 群聊视频

把视频链接或分享卡片发到群里，**@机器人** 提问；也可以引用那张卡片再 @机器人：

> @机器人 这个视频有哪些重点？UP主和观众的观点有什么区别？

### 搜索视频

> 帮我在 B站找几条最近的 Apex 新赛季攻略视频。

搜索需要聊天模型支持工具调用，并在当前会话中启用本插件的工具。

### 继续追问

分享之后，可以问「UP主是谁」「热门评论怎么看」。指定更早的视频时，请引用对应卡片或重新发送链接。最近分享记录按群聊、私聊分别保存，最长保留两小时；重启会清空内存记录，找不到原视频时请重新分享。

## 常用设置

在 **插件 → B站内容读取 → 配置** 中修改：

| 设置 | 用途 | 建议起步值 |
| --- | --- | --- |
| `enabled` | 启用插件 | 开启 |
| `auto_read` | 回复分享内容时自动读取视频资料 | 开启 |
| `max_comments` | 最多读取的热门评论数量 | 24 条 |
| `cache_seconds` | 相同资料的缓存时间 | 600 秒 |
| `allowed_platforms` | 限制在哪些机器人实例上使用 | 留空，允许全部实例 |

## 常见问题

**能直接看到视频画面、听到视频声音吗？**

当前读取的是视频资料、可用字幕和部分评论，暂不分析视频画面与音轨。没有字幕时，回答依据是简介与评论，因此对视频的了解会有限。

**为什么有些视频读不到字幕？**

视频可能没有字幕，或当前账号、接口无法取得字幕。重新扫码能解决登录失效，但不保证每条视频都能读取字幕。多分P视频当前读取第一P的可用字幕。

**发了链接没反应怎么办？**

先到「账号与状态」验证登录，确认 `enabled` 和 `auto_read` 已开启。群聊中请真正 @机器人并提问；私聊中可重新发送完整链接，再问一个具体问题。

**插件安装失败怎么办？**

在 AstrBot 日志中查看插件依赖安装错误。可以把错误和本仓库链接交给 Agent，请它在 AstrBot 实际使用的 Python 环境中，按 `requirements.txt` 补装依赖后重新加载插件。

**会增加模型费用吗？**

读取 B站资料本身不调用语言模型。机器人回答时，视频资料、字幕和评论会增加聊天模型的输入用量。

## 数据与备份

- 插件数据及登录状态：`data/plugin_data/astrbot_plugin_bili_reader/`。
- 插件配置：`data/config/astrbot_plugin_bili_reader_config.json`。

备份时同时保存这两项，登录数据请妥善保管。卸载插件后，已保存的登录文件需要自行处理。
