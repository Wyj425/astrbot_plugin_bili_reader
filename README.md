# B站内容读取

适用 AstrBot **4.29.3 及以上**，Python 3.12；当前实际验证版本为 AstrBot 4.29.3。其他版本需自行验证兼容性。

- 关键词搜索视频，读取视频信息、UP主、粉丝数与互动数据。
- 读取可用字幕的节选、部分热门评论；没有字幕时退回简介，明确资料类型。
- 自有扫码登录页，不依赖 biliread。无需单独模型总结，交给当前聊天模型回答。
- 支持 BV 号、视频链接、b23.tv 短链。不能读取付费/无权限内容；不会下载整段视频进行视觉分析。

## 安装

1. 本插件仓库：[Wyj425/astrbot_plugin_bili_reader](https://github.com/Wyj425/astrbot_plugin_bili_reader)，由 `Wyj425` 维护。
2. 在 AstrBot → 插件 → 从链接安装，填写 `https://github.com/Wyj425/astrbot_plugin_bili_reader`；也可导入只包含本目录的 ZIP。不要上传整个工作目录。
3. AstrBot 按 `requirements.txt` 安装 Python 依赖。启用插件后，在插件配置页设置。
4. 可独立安装，不依赖社区精选、点歌或其他三个能力插件。

## 使用与登录

进入插件视图「账号与状态」，先点「验证当前登录」，需要时点击「获取登录二维码」，使用对应平台 App 扫码并确认。二维码过期可重新获取；网站要求验证码或设备确认时由管理员完成，不自动绕过。

在私聊分享链接，或在群内真正 @机器人并引用卡片，要求「读一下正文、图片和评论」。群消息是否触发回复仍由 AstrBot/群聊回复规则决定；本插件不主动群发。

自动读取会把已下载图片像素加入本次模型请求，需要当前模型支持视觉。模型工具的读取返回文字证据，不附图片像素，因此不能仅凭工具结果猜图。搜索/读取工具由模型按需要选择；工具返回的内容不代表平台或管理员的指令。

追问关联规则：当前消息的分享链接优先，其次是明确引用的卡片；“这个视频/这篇帖子”之类的追问跟随消息到达时本会话最近的分享内容，三个平台共同遵守同一个选择结果。明确指定平台时可查找该平台较早的分享。引用记录按完整群聊/私聊会话隔离，最长保留两小时，追问不会延长原链接有效期。

## 数据、费用与卸载

插件数据保存在 AstrBot 的 `data/plugin_data/astrbot_plugin_bili_reader/`，配置位于 `data/config/astrbot_plugin_bili_reader_config.json`。扫码凭据不返回到模型、聊天或普通日志。平台搜索/详情缓存按公开内容共享，会话最近链接按完整会话标识隔离；重启清空内存缓存，候选库与发送记录等业务数据库仍持久化。

平台读取与签名本身不调用语言模型。正文、评论和配图进入聊天模型时会增加输入用量；社区评分、兴趣分析、人设短评及知识提取仍按各插件设置计费。没有无限抓取或无限评论翻页。

卸载插件不会自动清除平台账户的远程登录，也不应直接删除需要保留的数据。停用平台插件后，消费者会报告依赖不可用或跳过该平台。需要重新安装时恢复本插件目录及配置；平台失效需重新扫码。
